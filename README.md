# ⚡ KeyFlip Pro

**KeyFlip Pro** is a modern, lightweight desktop utility that grants you complete control over your keyboard layout. Built with an asynchronous low-level input listener, it runs seamlessly in the system background without lagging, dropping inputs, or getting blocked by web browsers like Google Chrome.

## 🚀 Features
* **Natively Block Any Key:** Instantly suppress specific keys (like CapsLock or Windows Key) so they do nothing when pressed.
* **Global Remapping:** Redirect any key input to execute a completely different key action (e.g., turning `Alt` into `Space`).
* **Persistent Background Execution:** Keeps working flawlessly while minimized, allowing you to play games, browse the web, or write code.
* **Modern GUI Dashboard:** A clean, easy-to-use graphical interface powered by CustomTkinter—no confusing command-line arguments or text files required.
* **Zero Dependencies for End Users:** Compiles into a single standalone executable (~10MB) that runs instantly without needing Python installed on the target machine.

## 🛠️ How to Use
1. Download and run **KeyFlip Pro** (Run as Administrator is required to hook Windows global keyboard events).
2. Type the key you want to block in the **Disable a Key** section.
3. Use the **Redirect a Key** fields to establish custom remapping pathways (e.g., `alt` ➔ `space`).
4. Click **▶ START REMAPPER** to activate your rules globally.
5. Click **⏸ PAUSE** or reset the board at any time to revert to standard Windows inputs.
